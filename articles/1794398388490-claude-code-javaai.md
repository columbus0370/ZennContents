## 概要
Claude Codeを活用してJavaプロジェクトの単体テスト自動生成を試した実験レポート。効果測定中の段階だが、手応えと課題を共有する。

## 構成
1. はじめに（背景と目的）
   - 単体テスト作成の工数問題
   - Claude Codeに期待したこと

2. 環境構築
   - Claude Code のセットアップ
   - Java + JUnit5 + Mockitoの構成
   - プロジェクト構造の説明

3. 実験：サービスクラスのテスト自動生成
   - 対象クラスの選定基準
   - プロンプトの工夫（コンテキスト提供、出力形式指定）
   - 生成されたテストコードの実例

4. 結果と考察
   - 正常系テストの品質：概ね良好
   - 異常系・境界値テスト：追加プロンプトが必要
   - Mockの使い方：指示が明確なら正確

5. 課題と改善点
   - 既存テストとの整合性
   - カバレッジの偏り
   - レビュー必須の領域

6. まとめと今後の展望
   - 「下書き生成ツール」としての位置づけ
   - 継続検証のポイント
